После применения манифеста проверим, может ли пользователь достучаться до `ns`

По-умолчанию пользователю даются все права через:

```
rules:
- apiGroups: ["*"]
  resources: ["*"]
  verbs: ["*"]
```

Чтобы ограничить, необходимо добавить ограничения. В `resources` добавляется, например `pods`, то есть к чему нужно получить доступ. в `verbs` указывается какие действия будут разрешены. `apiGroups` - для версий

```
rules:
- apiGroups: [""]
  resources: ["pods", "services"]
  verbs: ["list"]
- apiGroups: ["apps"]
  resources: ["deployments"]
  verbs: ["list"]
```

Ограничения создаются либо если мы заранее знаем, что нужно пользователю, либо методом пробы ошибок - пользователь жалуется, что получает ошибку `Forbidden` и мы как администратор кластера добавляем то, что описано в ней

##### Verbs

| Verb               | Что делает                                                                                               |
| ------------------ | -------------------------------------------------------------------------------------------------------- |
| `get`              | Прочитать один объект по имени.                                                                          |
| `list`             | Получить список объектов.                                                                                |
| `watch`            | Следить за изменениями объектов в реальном времени.                                                      |
| `create`           | Создать новый объект.                                                                                    |
| `update`           | Полностью заменить существующий объект.                                                                  |
| `patch`            | Частично изменить объект.                                                                                |
| `delete`           | Удалить один объект.                                                                                     |
| `deletecollection` | Удалить несколько объектов, например по label selector.                                                  |
| `impersonate`      | Действовать от имени пользователя, группы или serviceaccount.                                            |
| `bind`             | Создавать `RoleBinding` / `ClusterRoleBinding` на эту `Role` / `ClusterRole` без полного доступа к RBAC. |
| `escalate`         | Создавать или изменять `Role` / `ClusterRole` с правами, которых у вас самих нет.                        |
| `approve`          | Одобрять `CertificateSigningRequest` (CSR).                                                              |
| `sign`             | Подписывать CSR.                                                                                         |
