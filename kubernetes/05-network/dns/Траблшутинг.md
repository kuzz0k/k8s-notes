##### 4. Логи `localdns`

### nodelocaldns dial tcp 10.233.0.3:53:i/o timeout

Частая ошибка из логов `localdns`, которая говорит, что он не может получить доступ к основному DNS серверу. В подавляющем большинстве случаев **проблема с сетью**

Такое бывает при добавлении новой ноды

### То работает, то не работает

1. Причина может быть в том, что на ноду поселился `coredns` и сервис поочередно спрашивает то один `coredns` на одной ноде, то на другой
2. Причина может быть в том, что в `/etc/resolv.conf` есть несколько DNS серверов. `localdns` берет сначала данные от первого, кэширует - всё норм. Данные истекают - берет новые из следующего DNS сервера - ошибка
