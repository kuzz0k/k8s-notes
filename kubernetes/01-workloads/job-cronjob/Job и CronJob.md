Предназначена для разового запуска пода. Если под будет запущен с exit 0, то job останется, а под остановится, но не удалится, чтобы можно было посмотреть логи. В противном случае, когда exit не 0, job контроллер будет пытаться запустить под еще несколько раз (задается через `backoffLimit: 4`), с разной периодичностью.

```
kubectl -n work get jobs
```

В списке подов не хранятся поды напрямую, хранятся лишь их записи в бд, ресурсы кластера они не едят

Если необходимо чтобы поды удалялись, то в спецификации нужно написать:

```
spec:
  ttlSecondsAfterFinished: 100
```

Но важно помнить, что после удаления нельзя будет посмотреть логи

# CronJob

```
kubectl -n work get cronjobs
```
